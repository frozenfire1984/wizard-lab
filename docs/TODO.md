  Выразить типом можно кортежем:

  ```ts

  ```

- [ ] **Автодеплой на второй мак по push.**
  **Self-hosted runner** GitHub Actions: ставится на второй мак, сам подключается к GitHub
  наружу — работает за роутером, без белого IP и проброса портов.

  ```yaml
  on: { push: { branches: [main] } }
  jobs:
    deploy:
      runs-on: self-hosted
      steps:
        - uses: actions/checkout@v4
        - run: docker compose up -d --build
  ```

  ⚠️ **Только для приватного репозитория.** На публичном любой pull request выполнит свой код
  на твоей машине. Проверить видимость `wizard-lab` перед настройкой.
  Попутно разберёшься с GitHub Actions — на работе это пригодится больше, чем сам докер.
  Проще вариант без Actions: cron на втором маке с `git pull` и пересборкой.
  Доступ из интернета (если понадобится) — Cloudflare Tunnel: бесплатен, работает за NAT,
  адрес постоянный. У ngrok в бесплатном тарифе адрес меняется при каждом запуске.

## Хвосты и мелочи

- [ ] **Разобрать на свежую голову: `null` внутри псевдонима типа.** Записано 18.10.2026 в 4 утра,
  правка сделана по ходу, но понимание нужно закрепить.
  Было:

  ```ts
  export type Timestamp = number | null
  ```

  `null` зашит **внутрь имени** — и везде, где стоит `Timestamp`, автоматически разрешается
  «ничего», даже там, где значение точно есть. В `SubmitOrderResponse.date` сервер дату
  возвращает всегда, но компилятор требует проверки на `null`, которой быть не должно.

  Как честнее:

  ```ts
  type Timestamp = number        // просто число

  date: Timestamp                // там, где дата точно есть
  date: Timestamp | null         // там, где её может не быть — видно в месте использования
  ```

  **Правило:** имя типа говорит, **что это**. Может ли значение отсутствовать — свойство
  конкретного места, а не самого типа.

  Тот же случай, что `string | ''` и `DeliveryMethod | 'pickup'`: не прятать особенности внутрь
  имени, пусть будут видны там, где используются.
  См. `KNOWLEDGE/cheatsheets/типы-и-интерфейсы.md`.

- [ ] **Увидеть 404 на прямом заходе живьём** (отложено 24.09.2026, принято на веру).
  `npm run build` → `python3 -m http.server -d dist 8000` → зайти на `/about` и нажать F5 → 404.
  Потом `npm run preview` — та же сборка, но с SPA-fallback, F5 работает.
  Суть: клик внутри приложения обрабатывает роутер в браузере, прямой заход — сервер;
  в бою серверу нужен `try_files $uri $uri/ /index.html`. Актуально станет на деплое.
