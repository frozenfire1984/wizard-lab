# docs — карта папки

Здесь только то, что относится к **этому** проекту. Всё общее на учебный трек — шпаргалки,
разборы, грабли окружения — лежит в [KNOWLEDGE](../../KNOWLEDGE/README.md), соседней папке
в `~/PET_Projects/`.

Правило раздела: что переживёт проект — в KNOWLEDGE; что умрёт вместе с ним — здесь.

| Файл | Что там |
|---|---|
| [COURSE](COURSE.md) | план курса: вехи, критерии «готово», контракт фейкового API, список «что нести на работу» |
| [TODO](TODO.md) | живая очередь ближайших шагов |

`CLAUDE.md` лежит **в корне проекта, а не здесь** — Claude Code читает его оттуда автоматически
при старте сессии. Из папки он подхвачен не будет.

## Куда что писать

- **Разобрался в чём-то по Vue, TS, роутеру, тестам** → заметка в `KNOWLEDGE/notes/`.
- **Сводка или таблица, которую перечитывают целиком** → `KNOWLEDGE/cheatsheets/`.
- **Грабли инструмента или окружения** → `KNOWLEDGE/REMINDERS.md`.
- **Шаг курса, веха, критерий приёмки** → [COURSE](COURSE.md).
- **Ближайшее дело** → [TODO](TODO.md).
- **Находка для рабочего realmo** → раздел «📋 Что нести на работу» в [COURSE](COURSE.md),
  в формате *симптом → причина → что предложить*.

Форматы заметок и конвенции имён описаны в [KNOWLEDGE](../../KNOWLEDGE/README.md).
