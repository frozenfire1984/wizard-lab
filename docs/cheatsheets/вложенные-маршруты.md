# Вложенные маршруты — правила

> 24.09.2026. Правила работают, **механика осознана не до конца** — вернуться к разбору
> на вехе 1 из [COURSE](../COURSE.md). Сейчас достаточно «делать так».

## Правило 1 — путь в `children` пишется относительно родителя

```ts
{ path: '/shop', component: ShopView, children: [
    { path: 'gifts', component: ShopGiftsView },   // → /shop/gifts
]}
```

Как `cd` в терминале: `cd gifts` — относительно текущей папки, `cd /shop/gifts` — от корня.
**Ведущий слэш отключает склейку с родителем.** Родитель переименуется — дети за ним не поедут.

## Правило 2 — дочерний маршрут с `path: ''` обязателен

Иначе адрес родителя (`/shop`) показывает шапку раздела и **пустоту** под ней:
внутреннему `<RouterView />` нечего рисовать.

## Правило 3 — имя маршрута вешать на `path: ''`, а не на родителя

```ts
{ path: '/shop', component: ShopView, children: [      // ← без name
    { path: '', name: 'shop', component: ShopDefaultView },   // ← name здесь
]}
```

Имя указывает на **конкретную запись**, а не на адрес. Имя на родителе → переход
`router.push({ name: 'shop' })` выбирает родителя, цепочка обрывается, внутренний
`RouterView` пуст. При этом клик по `<RouterLink to="/shop">` работает — переход по пути идёт
по дереву и находит дочернее звено. **Глазами баг не виден**, видно только в консоли:

```
[VUE_ROUTER_R0103] The route named "shop" has a child without a name, an empty path,
and no children. Using that name won't render the empty path child.
```

## Механика (к которой вернуться)

Адрес совпадает не с одним маршрутом, а с **цепочкой** — список лежит в `matched`:

```
/shop/gifts  →  matched = [ ShopView, ShopGiftsView ]

App.vue
  <RouterView />            ← звено 0 → ShopView
      └── ShopView.vue
            <RouterView />  ← звено 1 → ShopGiftsView
```

Каждый `<RouterView />` рисует своё звено по глубине вложенности. Вложенность компонентов
повторяет вложенность маршрутов.

Проверить руками, не открывая браузер, — временный файл в корне проекта:

```js
import { createRouter, createMemoryHistory } from 'vue-router'
const C = { render: () => null }
const router = createRouter({ history: createMemoryHistory(), routes: [/* ... */] })
console.log(router.resolve({ name: 'shop' }).matched.length)  // 1 = баг, 2 = ок
console.log(router.resolve('/shop').matched.length)
```

## Привычка на будущее

Переходы делать **по имени**, а не по строке пути: адреса тогда меняются в одном месте,
а `RouterLink` и `router.push` об этом не знают. Разберём на вехе 1.
